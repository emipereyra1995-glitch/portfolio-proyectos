## Cómo trabajo con IA

Utilizo Codex para apoyar la especificación, la planificación, la implementación, el diagnóstico y la revisión. La documentación de cada caso distingue la ayuda de IA de las funciones de la aplicación y de las comprobaciones realizadas. Los proyectos no se presentan como entrenamiento de modelos ni como aplicaciones con LLM integrado cuando no lo incorporan.
