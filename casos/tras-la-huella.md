# Tras la Huella · Reportes de animales perdidos

## Problema y solución

Proyecto comunitario para publicar y consultar reportes de animales perdidos, con uso desde teléfonos. La adaptación PWA permite instalar el sitio conservando la base PHP/MySQL.

## Tecnologías y funciones documentadas

PHP, MySQL, JavaScript, manifest y service worker. Se documentan acceso a cámara, geolocalización, compartir desde el celular y pantalla sin conexión. La caché de recursos evita almacenar APIs y datos sensibles.

## Evidencia

El chat de adaptación móvil registra comprobaciones locales de sintaxis PHP/JavaScript, manifiesto y flujo móvil. No se ejecutaron nuevamente para este caso. La instalación en teléfonos fuera de localhost requiere HTTPS.

## Límites

No se afirma cantidad de usuarios, animales encontrados, disponibilidad pública ni publicación en tiendas de aplicaciones. No se incluyen reportes, ubicaciones o imágenes de personas reales. Código privado.
