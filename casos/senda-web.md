# Senda Web · Servicios y consultas comerciales

## Problema y solución

Sitio de un estudio de diseño y desarrollo web: presenta servicios y modelos de sitios, permite explorar demos visuales y registrar solicitudes de presupuesto. Un panel privado organiza las consultas.

## Tecnologías y decisiones

PHP, PDO, MySQL, HTML, CSS y JavaScript. Catálogo público separado del panel administrativo. Los formularios incorporan validaciones, CSRF y controles contra envíos repetidos. El proyecto documenta migraciones y creación de administradores desde consola.

## Qué muestra en mi portfolio

Trabajo de desarrollo asistido por IA sobre un producto web: definición del alcance, interfaz, formularios, persistencia, administración y pruebas. No se atribuyen clientes, ventas o tráfico al proyecto.

## Evidencia disponible

El README documenta pruebas de catálogo, formularios, base de datos y administración. No se ejecutaron nuevamente para preparar esta presentación. No hay demo pública verificada en este caso.

## Límites

Las demos del catálogo son visuales: no procesan pagos, reservas ni operaciones reales. El transporte de correo está pendiente y el portfolio comercial requiere material autorizado. No se presenta como sitio desplegado ni listo para producción. Código privado.

## Recorrido de demo propuesto

Catálogo → modelo → demo visual → consulta con datos ficticios → revisión de la consulta en administración.
